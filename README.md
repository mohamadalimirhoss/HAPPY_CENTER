.# HAPPY CENTER — Android starter

A Persian RTL Android storefront prototype built with Kotlin + Jetpack Compose.

## Included
- Home screen and brand header
- Product categories and sample product cards
- Add-to-cart counter and cart placeholder
- Account placeholder
- Privacy-conscious packaging messaging

## Build
1. Open this folder in Android Studio (recent version).
2. Allow Gradle sync and install the Android SDK 35 if prompted.
3. Run the `app` configuration on an emulator or Android device.

## Before publishing in Iran
- Replace sample items with real, legally sourced products and accurate labels.
- Add a backend/database, inventory, order management, SMS OTP, payment gateway,
  shipping integration, privacy policy, support details, and admin dashboard.
- Verify applicable Iranian rules for online sale, product approvals, age/access
  requirements where relevant, e-commerce trust/permits, payment, and advertising.
- Do not collect sensitive information unless necessary; protect phone/address/order data.
- Confirm the final spelling/branding: this starter uses “HAPPY CENTER” exactly as supplied.

This is a starter source project, not a signed APK and not yet connected to live payments.
